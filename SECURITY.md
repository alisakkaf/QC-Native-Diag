## Reporting a Vulnerability

If you discover a security vulnerability or potential protocol flaw within **Mini Diag Tool**, please report it responsibly:

1. **Email:** Contact the developer directly via [https://alisakkaf.com/](https://alisakkaf.com/)
2. **GitHub Security Advisory:** Submit a private disclosure report on [QC-Native-Diag Security](https://github.com/alisakkaf/QC-Native-Diag/security)

Please include:
- Detailed description of the vulnerability.
- Steps to reproduce or proof of concept payload.
- Affected chipsets or operating system versions.

All valid reports will be addressed promptly.
